## 📌 Objective

The objective of this project is to apply **customer segmentation techniques** using **RFM analysis and K-Means clustering** to group customers based on their purchasing behaviour and support **targeted marketing and customer retention strategies**.

**Dataset Used:** `Online Retail.csv` (E-commerce Transaction Dataset)

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Scikit-learn (KMeans)
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Analysis Performed

* Dataset loading and preprocessing
* Missing value handling and data cleaning
* Descriptive statistics for customer purchase behaviour
* RFM feature engineering (Recency, Frequency, Monetary)
* Data normalization using `StandardScaler`
* Elbow Method implementation to determine the optimal number of clusters
* K-Means clustering model training
* Cluster visualization using scatter plots
* Cluster profiling based on mean feature values
* Customer count analysis for each cluster
* Marketing recommendations for each customer segment

---

## 📈 Key Insights

* Identified **high-value loyal customers** who contribute significantly to revenue.
* Detected **frequent but low-spending customers** suitable for upselling campaigns.
* Recognized **inactive or at-risk customers** who may require re-engagement strategies.
* Demonstrated how clustering can improve **personalized marketing decisions**.
