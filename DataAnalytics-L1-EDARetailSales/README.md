## 📌 Objective

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a retail sales dataset to uncover **sales trends, customer behaviour patterns, product performance insights, and actionable business recommendations**.

**Dataset Used:** `Sample - Superstore.csv` (Superstore Retail Dataset)

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Analysis Performed

* Dataset loading and structure inspection
* Null value and data type analysis
* Descriptive statistics for numerical features
* Monthly and quarterly sales trend analysis
* Customer age-group distribution analysis
* Gender-wise customer segmentation
* Top 10 best-selling products identification
* Revenue by product category visualization
* Correlation heatmap for numerical variables
* Additional insight-driven visualization for deeper business understanding

---

## 📈 Key Insights

* Identified seasonal patterns in sales performance.
* Determined the highest revenue-generating product categories.
* Observed customer demographic trends that can support targeted marketing strategies.
* Highlighted relationships between key numerical variables using correlation analysis.
