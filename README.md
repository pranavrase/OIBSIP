## 📊 Completed Level 1 Tasks

### 1️⃣ EDA on Retail Sales Data

**Dataset:** `Sample - Superstore.csv`

**Objective:** Perform exploratory data analysis on retail sales data to identify trends, customer behaviour patterns, product performance insights, and actionable business recommendations.

**Key Highlights:**

* Dataset inspection and null value analysis
* Descriptive statistics
* Monthly and quarterly sales trends
* Customer demographic analysis
* Top-selling products and category-wise revenue analysis
* Correlation heatmap and additional visual insights

**Tools Used:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

---

### 2️⃣ Customer Segmentation Analysis

**Dataset:** `Online Retail.csv`

**Objective:** Apply **RFM analysis and K-Means clustering** to segment customers based on purchasing behaviour and recommend targeted marketing strategies.

**Key Highlights:**

* Data preprocessing and cleaning
* RFM feature engineering
* Data standardization using `StandardScaler`
* Elbow Method for optimal cluster selection
* K-Means clustering and customer profiling
* Cluster visualization and marketing recommendations

**Tools Used:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

---

### 3️⃣ Cleaning Data

**Datasets:**

* `Titanic-Dataset.csv` (Original Dataset)
* `Titanic-Dataset-Cleaned.csv` (Cleaned Dataset)

**Objective:** Demonstrate professional data cleaning and preprocessing techniques by transforming a messy dataset into a clean, consistent, and analysis-ready dataset.

**Key Highlights:**

* Data quality assessment
* Missing value treatment
* Duplicate removal
* Standardization of inconsistent values
* Outlier detection and handling
* Data type correction
* Before vs. after data quality comparison
* Export of cleaned dataset

**Tools Used:** Python, Pandas, NumPy, Jupyter Notebook
