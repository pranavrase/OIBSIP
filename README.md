## 📂 Completed Tasks

### 1️⃣ EDA on Retail Sales Data

**Folder:** `DataAnalytics-L1-EDARetailSales`

**Objective:**
Perform a detailed exploratory data analysis on retail sales data to identify sales trends, customer behavior patterns, and business insights.

**Key Features:**

* Dataset inspection and null value analysis
* Descriptive statistics for numerical columns
* Monthly and quarterly sales trend analysis
* Customer demographic analysis
* Top-selling products and category-wise revenue analysis
* Correlation heatmap and additional visual insights
* Business recommendations based on findings

**Tools Used:**

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

### 2️⃣ Customer Segmentation Analysis

**Folder:** `DataAnalytics-L1-CustomerSegmentationAnalysis`

**Objective:**
Segment customers into distinct groups using **K-Means clustering** and **RFM analysis** to support targeted marketing strategies.

**Key Features:**

* Data preprocessing and missing value handling
* RFM feature selection (Recency, Frequency, Monetary)
* Data standardization using `StandardScaler`
* Elbow Method for optimal cluster selection
* K-Means clustering implementation
* Cluster visualization and profiling
* Segment-wise marketing recommendations

**Tools Used:**

* Python
* Pandas
* Scikit-learn (KMeans)
* Matplotlib
* Seaborn
* Jupyter Notebook

---

### 3️⃣ Cleaning Data

**Folder:** `DataAnalytics-L1-CleaningData`

**Objective:**
Transform a messy dataset into a **clean, consistent, and analysis-ready dataset** while documenting every data-cleaning decision.

**Key Features:**

* Data quality reporting
* Missing value treatment
* Duplicate detection and removal
* Standardization of inconsistent values
* Outlier detection using statistical methods
* Data type correction and validation
* Before vs. after data quality comparison
* Export of cleaned dataset to a new CSV file

**Tools Used:**

* Python
* Pandas
* NumPy
* Jupyter Notebook
