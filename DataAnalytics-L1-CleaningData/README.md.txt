## 📌 Objective

The objective of this project is to demonstrate **professional data cleaning and preprocessing techniques** by transforming a deliberately messy dataset into a **clean, consistent, and analysis-ready dataset**, while documenting every major cleaning decision.

Dataset Used:

Titanic-Dataset.csv (Original Dataset)
Titanic-Dataset-Cleaned.csv (Cleaned Dataset)

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Jupyter Notebook

---

## 📊 Cleaning Operations Performed

* Generated a **data quality report** (null values, duplicates, data type issues, and anomalies)
* Handled missing values using appropriate strategies such as mean, median, mode, and row removal
* Identified and removed duplicate records
* Standardized inconsistent categorical values and formatting
* Converted date columns to proper `datetime` format
* Corrected incorrect data types for IDs, dates, and numerical fields
* Detected outliers using statistical methods (IQR/Z-score approach)
* Created a **before vs. after** data quality comparison summary
* Exported the cleaned dataset to a new CSV file

---

## 📈 Key Insights

* Improved dataset consistency and reliability for downstream analysis.
* Reduced data quality issues caused by missing values and duplicates.
* Standardized categorical and date formats for easier processing.
* Produced a structured dataset suitable for **EDA, reporting, and machine learning workflows**.
